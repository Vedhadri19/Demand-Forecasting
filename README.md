# Demand-Forecasting
A time series forecasting project that uses historical sales data to analyze demand and predict future sales.

# Tools Used
Python, Pandas, NumPy, Matplotlib, Statsmodels, Prophet

# Process
*Explored and cleaned the sales data
*Handled missing values and converted dates
*Aggregated sales data on a weekly basis
*Analyzed demand trends over time
*Built and compared three forecasting models:
-Holt-Winters
-Exponential Smoothing
-Prophet
*Compared the forecasts to understand model performance
